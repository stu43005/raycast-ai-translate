# AI CLI Translate Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Two-pane AI Translate command backed by the Claude Code, Codex, Gemini CLI or GitHub Copilot CLI, or a custom command
- Source and target language selection with auto-detection and a second target language
- Dictionary mode for single words
- Translation style (natural / literal) and per-language formality, including Chinese 您/你 and Japanese keigo levels
- Taiwanese Hokkien and Hakka as source and target languages
- Persistent translation history in the left column; identical requests reuse the saved translation
